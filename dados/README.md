# Dados

Os dados utilizados neste projeto são públicos e foram obtidos no Portal de Dados Abertos do Governo Federal, no conjunto de ocorrências aeronáuticas da aviação civil brasileira do CENIPA/SIPAER.

Arquivos utilizados:

- ocorrencia.csv
- aeronave.csv
- ocorrencia_tipo.csv

Os arquivos não foram incluídos diretamente no repositório para evitar problemas de tamanho e versionamento.
